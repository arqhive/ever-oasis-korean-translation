# 에버오아시스 한글화 번역 지침

일본판(3DS, 0004000000164A00) 대사를 한국어로 옮길 때 지키는 규칙. 번역을 나눠 맡는 사람(또는 에이전트)은
작업 전에 이 문서와 아래 참고 자료를 반드시 읽는다.

## 참고 자료 (작업 폴더 `C:\Users\hgyst\Claude Work\에버오아시스` 기준)

| 파일 | 내용 |
|---|---|
| `translation/GLOSSARY.md` | 세계관·시스템·지명 핵심 용어와 결정 근거 |
| `translation/NAMES.md` | 인물 110명 표기(규칙 B, 확정) |
| `translation/terms.json` | 이미 번역한 이름·아이템·메뉴·지명 1,800여 개 (일본어 → 한국어). **대사에 나오는 고유명사는 반드시 여기서 찾아 쓴다** |
| `work/대조표/1차.md`부터 `4차.md`까지 | 먼저 번역한 시스템·메뉴 문구. 문체 참고용 |

영어판(`tools/dump_range.py` 출력 3번째 열)은 **참고만** 한다. 영어판은 이름을 바꾸고 의역을 많이 했다.
번역 기준은 언제나 일본어 원문이다.

## 작업 절차

1. 맡은 구간의 원문을 뽑는다.
   `python tools/dump_range.py 70000 70999 > work/text/_src_70a.txt`
   출력 형식: `ID <TAB> 일본어(제어코드 포함, 후리가나는 이미 제거됨) <TAB> 영어판`
2. 번역을 `translation/batches/batch<이름>.py` 에 쓴다(예: `batch70a.py`).
   ```python
   # -*- coding: utf-8 -*-
   """70a: ID 70000~70499 동료 대사"""
   KO = {
   70001: '그런데 당신 들었어?{01}카라 사막에 오아시스가 생겼대!{03}{02}...{03}{00}',
   }
   ```
   - 문자열 안의 제어코드는 원문에서 **그대로 복사**한다. 파이썬 문자열이므로 작은따옴표·역슬래시에 주의.
   - 한 파일에 수백 개씩 나눠 써도 된다(`batch70a.py`, `batch70b.py` …).
3. 검사한다. **통과할 때까지 고친다.**
   `python tools/apply_batch.py 70a --check`
   - 반영(`--check` 없이 실행)은 하지 않는다. `work/text/messages.json` 을 직접 고치지 않는다.
   - 경고(360px 초과)는 가능하면 줄인다. 오류는 반드시 없앤다.
4. 구간의 미번역 ID 가 모두 들어갔는지 확인한다(검사 도구는 넣은 것만 본다).

## 제어코드 규칙 (가장 중요)

원문에 있는 `{..}` 코드는 **종류와 개수가 번역문과 정확히 같아야 한다**(검사 도구가 대조한다).
위치는 한국어 어순에 맞게 옮겨도 된다.

| 코드 | 뜻 | 번역 시 |
|---|---|---|
| `{01}` | 줄바꿈 | **개수 유지**(= 페이지당 줄 수 유지). 줄바꿈 위치는 한국어에 맞게 옮겨도 된다 |
| `{02}` | 새 페이지 | 개수·순서 유지 |
| `{03}` | 입력 대기(페이지 끝) | 유지 |
| `{00}` | 메시지 끝 | 맨 끝에 하나 |
| `{05:xxxxxxxx}` | 선택지·응답 관련 | 원래 위치 근처 유지 |
| `{04:xxxxxxxx}` | 대기 시간(ms) | 유지 |
| `{09:xxxxxxxx}` | 화자 초상·음성 지정(문장 맨 앞) | 맨 앞 유지 |
| `{17}` `{18}` | 문단 정렬 등 | 원래 위치 유지 |
| `{19:00000002}…{19:ffffffff}` | 글자색 시작 … 해제 | 색을 입힐 **낱말을 감싸도록** 옮긴다 |
| `{0d}` | 주인공 이름(플레이어 입력) | 아래 조사 규칙 |
| `{0e:…}` `{13:…}` `{10:…}` `{11:…}` `{12:…}` `{0f:…}` | 이름·대상·아이템·숫자·값·가게 | 아래 조사 규칙 |
| `{08:xxxxxxxx}` | 버튼 아이콘 | "{08} 버튼을 누르면"처럼 풀어 쓴다 |
| `{15}A{z}{16}B{z}` | **주인공 성별 분기**: 남자면 A, 여자면 B | 두 칸을 각각 번역. 뒤 문장이 두 경우 모두 자연스럽게 |
| `{z}` | 성별 분기 구분자 | **개수 유지** |

**성별 분기는 원문에 없던 자리에도 추가할 수 있다.** 한국어에서만 성별이 갈리는 말(주인공의 お兄さん → 남자 주인공이면 `형`, 여자 주인공이면 `오빠`)은
`{15}형{z}{16}오빠{z}` 처럼 넣는다(검사 도구가 짝이 맞는 추가를 허용한다). 예: `네 {15}형{z}{16}오빠{z}는`, `{15}형이{z}{16}오빠가{z}`.
조사가 붙으면 조사까지 분기 안에 넣는다.

## 줄 폭

- 한글 한 글자는 16px. 대사창 한 줄 **360px(약 22자) 이하 권장, 400px 절대 초과 금지.**
- 원문 줄바꿈 개수는 그대로 두고, 넘치면 **문장을 줄이거나 같은 페이지 안에서 줄바꿈 위치를 옮긴다.**
- 한 페이지(`{02}` 사이)는 보통 2줄, 많아야 3줄이다. 도움말 창은 5줄까지 있다.

## 문체 규칙 (사용자 확정)

- **문장이 끝나면 마침표.** 원문이 `。`를 생략해도 종결어미로 끝나면 찍는다.
  메뉴 항목·명사구·고유명사에는 찍지 않는다. **줄임표(…)로 끝나면 마침표를 덧붙이지 않는다.**
- **명사형 원문은 명사형으로.** 마침표를 찍으려고 서술어를 새로 붙이지 않는다.
- **물결표 뒤에 다른 부호를 겹치지 않는다.** `~,` `~.` 금지, `~!` `~!!` 허용.
- **대사 속 3인칭 대명사 '그녀/그들' 금지.** 이름이나 '그 아이/그 애/그 사람'으로.
- **직역투 금지**: `이 내가`(この俺が) → `내가`, `~하는 것이다`, `~해 버렸다` 남발, `~하고 있다` 남발,
  `~에 대해`, `4개의 X` → `X 4개`, `이것을/그것을` → `이걸/그걸`, 끊긴 문장(`~だけど。` → `~지만.`)은
  종결어미나 말줄임표로 마무리.
- 외래어는 **국립국어원 외래어 표기법**(대미지, 메시지, 타깃 …).
- 띄어쓰기는 한국어 규범대로 **반각 공백**을 쓴다. 원문의 전각 공백(`　`)은 일본어 띄어쓰기 대용이므로
  대사에서는 옮기지 않는다(메뉴 표의 구분자로 쓰인 경우만 유지).

## 말투

- 원문 화자의 말투를 대응하는 한국어 말투로 옮기고, **같은 화자는 끝까지 일관되게** 한다.
  - 존댓말(です・ます) → 해요체/합쇼체, 반말 → 해체, 거친 말투 → 거친 반말
  - 노인·행상인(`〜ぞい` `〜じゃ` `ワシ`) → `~구먼`, `~라네`, `~지`, 1인칭 `나`/`이 늙은이`(`このワシ`), 상대 `자네`(`オヌシ`)
  - 아가씨·귀부인 말투(`〜わ` `〜のよ`) → `~해요`, `~거든요` 등 여성스러운 해요체 또는 반말
- 주인공은 오아시스의 **촌장**(`長`)이다. `長さん` → `촌장님`, `長` → `촌장`.
- `アナタ`/`キミ`/`オマエ` 는 문맥에 맞게 `당신`/`너`/`자네`, 또는 생략.
- 1인칭 강조 직역 금지: `オレ様` → `이 몸`은 허용.
- 의성어·감탄사는 한국어에 있는 것으로(`わわっ` → `으악`/`와와`, `えへへ` → `헤헤`).
- **간사이 사투리 화자(94000번대 악역 등)는 경상도 사투리로 옮긴다**(사용자 확정). 예: `待っとったでぇ` → `기다리고 있었다 아이가`, `深いんや` → `깊은 기라`, `ひねりつぶさせてもらうで` → `짓뭉개 주꾸마`. 과장하지 말고 억양이 드러나는 어미 위주로.

## 조사 처리 (사용자 확정: 혼합)

게임이 끼워 넣는 이름·아이템 뒤에는 받침 여부를 알 수 없다.

- 짧은 알림: 조사가 필요 없는 문형으로 — `[아이템] 획득!`, `파티 합류: [이름]!`, `[대상] ⏎ 달성!`
- 질문·대사처럼 문장이 필요한 곳: `을(를)`, `이(가)`, `은(는)`, `와(과)`, `(으)로` 병기
- `의`, `에`, `에게`, `도`, `만` 처럼 받침과 무관한 조사를 쓸 수 있으면 그쪽을 우선
- `{0d}`(주인공 이름)를 부를 때 호격 조사(`아/야`)를 붙이지 않는다: `저기, {0d}.`
- 끝 글자가 항상 정해진 자리(예: 축제 이름은 늘 '축제')는 맞는 조사를 바로 붙여도 된다.

## 고유명사

- 인명·지명·종족·아이템은 **`translation/terms.json` 과 인명표에 있는 표기를 그대로** 쓴다.
- 사전에 없는 새 고유명사를 정해야 하면, 인명·지명은 일본판 음차(규칙 B: 어말 ク·ル 받침 처리),
  뜻이 드러나는 말은 우리말로. 새로 정한 것은 **batch 파일 맨 위 주석에 `새 용어:` 목록**으로 남긴다.

## 주요 인물 말투 (앞선 번역에서 정해진 것, 반드시 맞출 것)

| 인물 | 말투 | 주인공 호칭 |
|---|---|---|
| 이스나(イスナ, 정령 소녀) | 친근한 반말 | `{0d}`, `너`. 다른 동료는 `○○ 씨` |
| 사후라(サフラー) | 부드러운 반말 | `촌장님` / `{0d} 씨` / `너` |
| 슈토(シュト) | 차갑고 거만한 해라체 | `너` |
| 로토(ロト) | 밝은 반말 | `너` |
| 리리샤(リリシャ) | 밝은 반말 | `{0d} 씨` |
| 미우(ミウ) | 차분한 여성 반말 | `당신` |
| 세셴(セシェン) | 여성스러운 해요체(`어머어머, 당신`) | `당신` |
| 행상인(`〜ぞい`) | `~구먼/~라네/~지`, 1인칭 `나` | `당신`(アナタさま) |
| 이루마의 주인(ヌシ) | 예스러운 해라체(`~거라/~리라`) | `그대` |
| 세르케족 장로 | 노인 하게체(`~구먼/~네`) | `자네` |
| 리코스족 장로 | 하오체(`~소/~구려`) | `그대` |
| 우아족 장로 | 예스러운 말투(`~거라/~느니라/~노라`) | `그대`(そなた) |
| 시스템 알림 | `~습니다!` | — |

- 주민 이름 뒤 `～さん` → `○○ 씨`, `さま` → `님`, `長老さん` → `장로님`, `精霊様` → `정령님`.
- 소문(ウワサ) 문장은 `~있다고 한다.` 로 통일.
