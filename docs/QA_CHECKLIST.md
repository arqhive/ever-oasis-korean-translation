# 에버오아시스 한글패치 QA 체크리스트

번역 8,503개(번역 대상 전부) + 이미지 글자 26종 교체 완료 빌드 기준.
원문·번역·영어판을 한 파일로 볼 때는 `work/전체_대조표.tsv`(원문이 들어 있어 저장소에는 없음)(엑셀에서 열림, 마지막 열이 QA 메모 칸).

## 0. 준비

- **Azahar**: 모드 폴더에 이미 반영되어 있다. `emu/EverOasis_JP.cxi` 로 실행하면 된다.
- **실기(Luma)**: `release/luma` 폴더를 SD 카드 루트에 덮어쓴다 → `sd:/luma/titles/0004000000164A00/`.
  - Luma 설정에서 `Enable game patching` 이 켜져 있어야 한다.
  - 한국판 본체이므로 같은 폴더의 `locale.txt`(`JPN JP`)로 지역을 일본으로 맞춘다.
  - **같은 폴더에 예전 패치 파일이 남아 있지 않은지 먼저 확인**(페데레이션 포스 때 헛테스트 원인).

## 1. 기술 확인 (먼저 봐야 할 것)

| # | 확인할 것 | 어디서 | 안 되면 |
|---|---|---|---|
| 1 | **성별 분기 추가(64곳)** — 주인공의 형/오빠(니아카), 살로메의 누나/언니 등. 원문에 분기가 없던 자리에 넣었다 | 새 게임 프롤로그(니아카의 오아시스, ID 90000번대)를 남·여 주인공으로 각각 | 중립 표기로 되돌림(도구 있음) |
| 2 | **이름 입력** — 한글 이름을 입력할 수 있는지 | 새 게임 → 이름 입력 | 영문 입력만 되면 안내문 추가 |
| 3 | 아래 화면(폭 320px) 문구가 잘리지 않는지 | 메뉴, 꽃상점 화면, 할 일 목록 | 알려 주시면 줄임 |
| 4 | 긴 대사 줄이 대사창(400px)을 넘지 않는지 | 전반 | 알려 주시면 줄임 |
| 5 | `・` 가운뎃점(상처약・소 등)이 `*`로 나오지 않는지 | 아이템 목록 | 폰트 수정 |
