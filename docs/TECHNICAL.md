# 기술 문서

일본판 「エバーオアシス 精霊とタネビトの蜃気楼」(CTR-P-BAGJ, `0004000000164A00`, v0.0.0) 기준입니다.
Grezzo 엔진이며, 한글화에 필요한 파일은 모두 romfs의 `data/Region_JP/` 아래에 있습니다.

## 원본 추출

CIA는 seed 암호화되어 있습니다. [pyctr](https://github.com/ihaveamac/pyctr)에 `boot9.bin`과 `seeddb.bin`을 주면 바로 읽힙니다.
`tools/extract.py`가 `BOOT9_PATH`·`SEEDDB_PATH` 환경 변수나 Azahar의 `%APPDATA%\Azahar\sysdata\`를 찾아 씁니다.

## GMSG (텍스트)

```
0x00  "GMSG"
0x04  u32 버전 (3)
0x08  u32 인코딩 (일본판 1 = UTF-16LE, 영어판 2 = 1바이트)
0x0C  u32 메시지 수 (8,515)
0x10  u32 엔트리 표 오프셋 (0x2000)
엔트리 16바이트: u32 ID, u32 스타일, u32 절대 오프셋, u32 바이트 길이
```

문자열 영역은 다시 쌓고 오프셋 표만 고치면 됩니다. 원본을 그대로 다시 쓰면 바이트가 같게 나옵니다.

### 제어 코드

`7F 00` 뒤에 u16 코드가 옵니다. 도구에서는 `{xx}` 또는 `{xx:인자8자리}`로 씁니다.

- 코드 `04 05 06 08 09 0a 0e 0f 10 11 12 13 19`만 u32 인자를 하나 가집니다.
- **인자는 메시지 시작 기준 4바이트 경계에 정렬되고, 모자라는 만큼 0으로 채웁니다.** 번역으로 앞 글자 수가 바뀌면 채움 길이도 달라지므로 다시 계산해야 합니다. 원문 재조립은 바이트가 같게 나와서 왕복 검사로는 이 문제가 드러나지 않습니다.
- 문자열 안의 NUL은 `{z}`로 씁니다.

| 코드 | 뜻 |
|---|---|
| `{00}` | 끝 |
| `{01}` `{02}` `{03}` | 줄바꿈, 페이지 넘김, 입력 대기 |
| `{0d}` | 주인공 이름 |
| `{0e}` `{0f}` `{10}` `{11}` `{13}` | 동료 이름, 가게, 아이템, 숫자, 대상(지명·칭호) |
| `{08}` | 버튼 아이콘 |
| `{19}` | 글자 색 (`ffffffff`는 원래 색) |
| `{04}` | 대기(ms) |
| `{09}` | 얼굴 그림 |
| `{15}A{z}{16}B{z}` | 주인공 성별 분기 (남자 A, 여자 B) |
| `{1a}읽기{z}본문{1b}` | 후리가나 (한글판에서는 뺌) |

주인공의 형(お兄さん)처럼 한국어에서 성별에 따라 호칭이 갈리는 자리에는 원문에 없던 `{15}형{z}{16}오빠{z}` 분기를 넣었습니다.

## GZFX (폰트)

```
0x14  u32 글리프 수
0x28  u32 세로 칸 피치 (22)
0x30  u32 텍스처 오프셋 (128바이트 정렬 필수)
0x34  u16 너비, u16 높이 (1024 × 1024, A4 4bpp, 3DS 모턴 타일)
0x38  글리프 표 12바이트: u32 코드(오름차순), u32 advance, u16 x, u8 열, u8 행
```

- 칸은 가로 20, 세로 22픽셀, 한 줄 51칸, 46줄로 모두 2,346칸입니다. 글리프 i는 `(i % 51 × 20, i // 51 × 22)`에 놓입니다.
- **텍스처 오프셋이 128바이트 배수가 아니면 게임의 모든 글자가 사라집니다.**
- 폰트에 없는 글자는 게임이 `*`로 대신 그립니다.
- 한자, 가나(가운뎃점 `・`와 장음 `ー`는 유지), 그리스·키릴 문자 등을 빼서 칸을 비우고 한글 1,774자를 넣었습니다. 넣을 음절은 번역문에 쓰인 글자에 음절 빈도표(`tools/data/syllable_freq.json`) 순서로 나머지를 채웁니다.
- 원본 글리프는 또렷한 본체와 반투명 테두리로 되어 있어 게임이 테두리를 어둡게 칠합니다. 한글도 Gothic A1 Bold 14px 본체 바깥에 50%·23% 테두리 두 겹을 둘러 그립니다(`tools/hangul.py`).

## GAR·ctxb (그림 글씨)

- GAR v5: 헤더 `u32 크기, u16 타입 수, u16 파일 수, u32 타입 표, u32 파일 표, u32 데이터`, 파일 표 16바이트 `{u32 크기, u32 오프셋, u32 이름, u32 전체 이름}`.
- ctxb 텍스처는 3DS PICA 형식(ETC1, ETC1A4, RGBA4 등)입니다. `tools/ctxb.py`가 읽고, `tools/etc1.py`가 etcpak으로 블록을 압축한 뒤 3DS 배치(8×8 타일, 블록 바이트 순서 반전)로 씁니다.
- 텍스처 크기와 형식을 바꾸지 않고 GAR 안에서 그 자리만 덮어씁니다.

## HOME 메뉴 배너·아이콘 (ExeFS)

CIA를 다시 만들 때만 적용됩니다. LayeredFS로는 바뀌지 않습니다.

- `banner`(CBMD): `0x08` 공통 CGFX 오프셋, `0x0C`부터 지역별 CGFX 오프셋 16개(유럽 8, 일본, 미국 4, 중국, 한국, 대만), `0x84` CWAV 오프셋. CGFX는 각각 LZ11로 압축되어 있습니다.
- 영문 로고 `EverOasis_logo_JP_2`(512×128)는 모든 지역이 같습니다. 가타카나 제목과 부제 `EverOasis_logo_JP`(256×64, RGBA4)는 **일본 칸과 한국 칸에만** 있으며, 한국판 본체의 HOME 메뉴는 한국 칸을 읽습니다. 두 칸을 모두 바꿉니다(`tools/build_banner.py`).
- CGFX를 다시 압축하면 크기가 달라지므로 지역별 오프셋과 CWAV 오프셋(0x20 정렬)을 다시 씁니다.
- `icon`(SMDH): 언어 칸 12개에 짧은 제목 `에버 오아시스`, 긴 제목 `에버 오아시스⏎정령과 씨앗족의 신기루`를 씁니다. 게시자 `Nintendo`는 그대로 둡니다.

## 게임 스크립트 (화자 정보)

`data/scripts/*.gar` 속 `.gsb`는 Squirrel 3 바이트코드(`FAFA RIQS`, 정수 4바이트)입니다. `msg_sync_talk_event(대사 ID, 핸들)` 호출에서 대화 상대를 뽑아
`translation/speakers/`에 저장해 두었습니다. 번역 검수용이며 빌드에는 쓰지 않습니다(`tools/export_json.py`가 대사 목록을 내보낼 때 씁니다).
