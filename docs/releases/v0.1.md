닌텐도 3DS 「에버 오아시스」 일본판의 첫 한글 패치입니다. 게임 안 문구를 모두 번역했고, 대사는 일본어판 원문을 기준으로 삼았습니다.

**원본 일본판(`0004000000164A00`)에 적용하는 LayeredFS 패치입니다.** romfs 파일 23개를 통째로 바꿉니다.

## 변경 사항

- 대사, 의뢰, 메뉴, 아이템·특기 설명, 도움말, 할 일·동료 기록, 크레디트까지 게임 안 문구 8,503개를 모두 한글화했습니다.
- 본문 폰트의 한자·가나 칸을 비워 한글 1,774자(Gothic A1 Bold 기반)를 넣었습니다.
- 지역·던전 이름 17종, 레벨 업·랭크·초대성공·클리어·가드 팝 글씨, 타이틀 로고를 한글화했습니다.
- 주인공의 성별에 따라 형/오빠, 누나/언니처럼 호칭이 바뀌도록 했습니다.
- 외부 검토 의견 68건 가운데 63건을 반영했습니다(전투 불능과 기절 구분, 확인 버튼 표기 통일 등).
- 한국판·북미판 본체에서도 일본 지역으로 실행되도록 `locale.txt`(`JPN JP`)를 함께 넣었습니다.

## 배포 파일

| 파일 | 입력 | 설명 |
|---|---|---|
| `EverOasis_KO_v0.1.zip` | 원본 일본판 | SD 카드 루트에 푸는 LayeredFS 패치(`luma/titles/0004000000164A00/`)와 사용자 설명서, 라이선스. |

## 적용 방법

1. 3DS 실기: ZIP 안의 `luma` 폴더를 SD 카드 루트에 복사하고, Luma3DS 설정에서 **Enable game patching**을 켭니다.
2. Azahar: 게임을 오른쪽 클릭해 **Open Mods Location**을 열고, ZIP 안의 `luma/titles/0004000000164A00/romfs` 폴더를 그곳에 복사합니다.
3. 바뀐 파일의 확인값을 아래 표와 비교합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
