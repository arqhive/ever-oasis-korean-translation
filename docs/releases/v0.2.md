HOME 메뉴 배너·게임 이름을 한글화하고, 가지고 있는 일본판 CIA·3DS 파일을 한글판으로 바꾸는 패처를 추가했습니다. 게임 안 번역과 그림 글씨는 v0.1과 같습니다.

**원본 일본판(`0004000000164A00`)에 적용하는 전체 패치입니다.** 배포 파일 두 가지는 게임 안 한글이 같으며, 둘 중 하나만 고르면 됩니다.

## 변경 사항

- HOME 메뉴 배너의 제목 그림(`에버 오아시스` / `～ 정령과 씨앗족의 신기루 ～`)과 게임 이름을 한글로 바꿨습니다. 패처로 만든 CIA를 설치하면 적용됩니다.
- 일본판 `.cia`·`.3ds` 파일을 `패치하기.bat`에 끌어다 놓으면 게임 안 한글과 배너·게임 이름이 모두 들어간 한글판을 만드는 패처를 추가했습니다.
- LayeredFS 패치에서 `locale.txt`를 뺐습니다.

## 배포 파일

| | `EverOasis_KO_v0.2_LayeredFS.zip` | `EverOasis_KO_v0.2_Patcher.zip` |
|---|---|---|
| 방식 | 설치된 일본판에 SD 카드의 파일을 덮어씌움 | 일본판 CIA·3DS를 한글판으로 새로 만듦 |
| 게임 안 한글 | 적용 | 적용 |
| HOME 메뉴 게임 이름·배너 | 일본어 그대로 | 한글 |
| 필요한 것 | 이미 설치된 일본판, Luma3DS 게임 패치 설정 | 일본판 `.cia`·`.3ds` 파일, 윈도우 PC, 암호화된 원본이면 `boot9.bin`·`seeddb.bin` |
| 걸리는 시간 | 파일 복사 몇 초 | 패치 약 30초 + CIA 설치 |
| 되돌리기 | SD 카드의 폴더만 지우면 원래대로 | 원본 CIA를 다시 설치 |

설치된 게임을 그대로 두고 간단히 쓰려면 LayeredFS, HOME 메뉴까지 한글로 보고 싶거나 에뮬레이터용 한글판 파일이 필요하면 패처를 고르세요.

## 적용 방법

**LayeredFS**: ZIP 안의 `luma` 폴더를 SD 카드 루트에 복사하고, Luma3DS 설정에서 **Enable game patching**을 켭니다. Azahar는 **Open Mods Location**에 `romfs` 폴더를 복사합니다.

**패처**: ZIP을 폴더째 풀고 일본판 `.cia`나 `.3ds`를 `패치하기.bat`에 끌어다 놓습니다. 같은 폴더에 `_KO`가 붙은 한글판이 생기며, 3DS 실기에는 그 CIA를 설치합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
