그림 글씨를 전부 새로 그리고, 던전 이름이 일본어로 남던 곳을 찾아 고쳤습니다. 번역문은 v0.3과 같습니다.

**원본 일본판(`0004000000164A00`)에 적용하는 전체 패치입니다.** 배포 파일 두 가지는 게임 내 한글이 같으며, 둘 중 하나만 고르면 됩니다.

## 변경 사항

- 지역·던전 이름 17종, 팝 글씨(레벨 업!·랭크·초대성공·클리어!·가드), 타이틀 글자판과 로고, HOME 배너의 글자를 원본 디자인에 맞춰 새로 그렸습니다.
- **던전 이름 이미지가 게임 안에 두 벌 있는 것을 찾아 양쪽 모두 한글로 바꿨습니다.** `data/Region_JP` 쪽만 바꿔 두었던 터라, 게임이 `data/async` 쪽을 읽는 상황에서는 일본어가 그대로 보일 수 있었습니다.
- 덮어쓰는 romfs 파일이 23개에서 57개로 늘었습니다.
- 게임 안 텍스처 10,611장을 전부 훑어 글자가 있는 이미지를 다시 확인했습니다. 한글로 바꾼 것은 모두 79장이며, 원본이 영문인 `Ever Oasis` 로고·저작권 표기·`MAX`·엔딩 문구는 그대로 두었습니다.

## 배포 파일

| | `EverOasis_KO_v0.4_LayeredFS.zip` | `EverOasis_KO_v0.4_Patcher.zip` |
|---|---|---|
| 방식 | 설치된 일본판에 SD 카드의 파일을 덮어씌움 | 일본판 CIA·3DS를 한글판으로 새로 만듦 |
| 게임 내 한글 | 적용 | 적용 |
| HOME 메뉴 게임 이름·배너 | 일본어 그대로 | 한글 |
| 필요한 것 | 이미 설치된 일본판, Luma3DS 게임 패치 설정 | 일본판 파일 하나(3DS 실기 설치용이면 `.cia`, 에뮬레이터·플래시카트용이면 `.3ds`), 윈도우 PC, 암호화된 원본이면 `boot9.bin`·`seeddb.bin` |
| 걸리는 시간 | 파일 복사 몇 초 | 패치 약 30초 + CIA 설치 |
| 되돌리기 | SD 카드의 폴더만 지우면 원래대로 | 원본 CIA를 다시 설치 |

설치된 게임을 그대로 두고 간단히 쓰려면 LayeredFS, HOME 메뉴까지 한글로 보고 싶거나 에뮬레이터용 한글판 파일이 필요하면 패처를 고르세요.

## 적용 방법

**LayeredFS**: ZIP 안의 `luma` 폴더를 SD 카드 루트에 복사하고, Luma3DS 설정에서 **Enable game patching**을 켭니다. Azahar는 **Open Mods Location**에 `romfs` 폴더를 복사합니다. 이전 버전을 쓰고 있었다면 `sd:/luma/titles/0004000000164A00/` 폴더를 지우고 새로 복사하세요.

**패처**: 3DS 실기용이면 일본판 `.cia`, 에뮬레이터·플래시카트용이면 `.3ds` 하나를 준비합니다. ZIP을 폴더째 풀고 그 파일을 `패치하기.bat`에 끌어다 놓습니다. 같은 폴더에 `_KO`가 붙은 한글판이 생기며, 3DS 실기에는 그 CIA를 설치합니다.

자세한 방법은 동봉한 `README_한국어.txt`를 참고하세요.
