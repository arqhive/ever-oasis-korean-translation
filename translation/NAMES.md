# 인명표 (v1.0) — 규칙 B(받침 처리)

메시지 ID 1000~1370 구간에 있는 인물 110명.

## 표기 원칙

인명은 **일본판 이름을 기준**으로 한다. 토토·테테처럼 원음의 인상을 살리되, 한국어에서 자연스럽게 읽히도록
받침과 어말을 조정할 수 있다. 널리 알려진 이름의 관용형은 개별적으로 허용하고 비고에 근거를 적는다.
**영어판에서 바뀐 이름은 채택하지 않는다.**

세부 처리:

- 어말 ク·ル 은 받침·자음으로 줄인다 — 하노크, 이스하크, 포테파르, 니네체르, 타헤르.
- フ 는 이름답게 다듬어 '후' 또는 '프' 로 적는다 — 사후라, 자미레프, 파라프, 아슈라프. 한 쪽으로 강제하지 않는다.
- ツェ·ツォ·ツァ 는 체·초·차 로 적는다 — 체파, 벨초니, 모차.
- 장음 ー 는 생략하되, 같은 모음이 이어진 이름은 살린다 — 나아마, 사이이드, 메누우.

비고 표기: `익숙한 이름` = 한국어에서 굳은 인명 표기를 적용, `다듬음` = 일본어 음을 한국어 어감에 맞게 조정,
`어원 미확인` = 형태만 채택하고 유래는 확정하지 않음.
